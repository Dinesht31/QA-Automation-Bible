## 2. My Biggest Programming Challenge

My biggest challenge in programming has been developing confidence while solving logic-based problems. I want to improve my ability to break complex problems into smaller steps, understand the reasoning behind the code, and build solutions independently instead of relying on memorization.

I see this bootcamp as an opportunity to strengthen my problem-solving, debugging, and programming fundamentals through consistent practice.


---

## 3. My Bootcamp Habits

1. Understand and break a complex problem into smaller parts before writing code.
2. Attempt to think and write the solution myself before looking at tutorials or asking for help.
3. Push only reviewed and approved work to GitHub.
4. Revise previous lessons regularly because long-term understanding is more important than finishing quickly.
5. Never memorize blindly. Always ask **"Why does this work?"** and build an inquisitive engineering mindset.

## 4. What Does Clean Code Mean to Me Today?

Clean code is code that is readable by others, modular, simple to understand, and not unnecessarily complex.

## 5 Bootcamp Commitment

I will measure my progress by understanding concepts and improving my code quality, not by how quickly I finish lessons.
